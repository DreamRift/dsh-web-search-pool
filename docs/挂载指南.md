# dsh-web-search-pool 安装指南（rc.7 原生安装）

> 本文档适用于 dsh-web-search-pool >= 0.1.0-rc.7（DeepSeek Harness 0.1.0-rc.7+）

## 前置条件

- 已安装 **DeepSeek Harness 0.1.0-rc.7** 或更新版本
- 已有至少一个搜索 provider 的 API key（Tavily / Exa）

## 安装方式

### 方式一：tarball 安装（推荐）

```bash
# 在项目目录打包
npm pack

# 在 DSH profile 中安装
dsh plugin --profile web add ./dsh-web-search-pool-0.1.0-rc.7.tgz

# Windows PowerShell 示例
dsh plugin --profile web add ".\\dsh-web-search-pool-0.1.0-rc.7.tgz"
```

### 方式二：开发期 link 安装

```bash
dsh plugin --profile web add link:<项目目录>
```

> **注意**：link 模式直接读取源码，修改源码后需重新链接。生产环境推荐 tarball 模式。

## 安装后验证

```bash
# 检查组合树
dsh --profile web --dump-config

# 期望输出：
#   include:web                  config.searchProvider = search-pool
#   include:web-search-pool      name = dsh-web-search-pool

# 检查包解析
node -e "import('dsh-web-search-pool').then(m => console.log(m.name))"
```

## 配置 API Key

通过 DSH Settings UI 或在 `$DSH_HOME/profiles/web/settings.yaml` 中配置：

1. 打开 DSH Web
2. 进入设置 → 插件
3. 找到「搜索 Key 池」卡片
4. 点击展开，添加 Tavily / Exa key 引用和密钥
5. 保存配置

> 密钥仅通过 DSH credentials 服务保存，**不进入 settings.yaml 的非 secret 配置层**。

## 不再需要的步骤（rc.7）

以下操作在 rc.7 中**无需执行**：

- ❌ 运行 `node scripts/patch-api-proxy-namespace.mjs`
- ❌ 修改 DSH npm 安装目录
- ❌ 手工添加 `WEB_SETTINGS_NAMESPACES`
- ❌ 修改 shipped `cordis.yml`

## 卸载

```bash
dsh plugin --profile web remove dsh-web-search-pool
```
